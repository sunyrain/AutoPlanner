# Legacy Evaluation Data, May 2026

These benchmark JSON files support archived pre-V4 evaluation and diagnostic
entrypoints. They are not canonical V4 benchmark inputs.

- `benchmark_condition_rich_20260507.json`: condition-rich subset used by the
  archived skeleton-prior audit.
- `benchmark_locked_validation_20260508.json`: overlap-audited validation set
  generated by the archived locked-validation builder.
- `benchmark_gt_intermediate_seen_not_expanded_20260510.json`: historical
  candidate-miss diagnostic subset with no current code consumer.
- `benchmark_pairwise_stress_20260510.json`: historical pairwise stress subset
  with no current code consumer.
- `statin_smoke_2026-05-05.json`: early statin target smoke set with empty
  ground-truth routes and no current code consumer.

Current V4 benchmark inputs, including `data/benchmark_v2_100.json`, the
PaRoutes blind panel, and USPTO-190 assets, remain outside this directory.
