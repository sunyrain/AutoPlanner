# AutoPlanner GitHub Pages

This branch contains only the static AutoPlanner route showcase. It does not
contain the Python service, runtime registries, checkpoints, or local paths.

- `index.html`: showcase landing page
- `complete-route-graph.html`: draggable three-strategy route graph
- `static-route.html`: final static route for Strategy 03
- `model-interaction.html`: saved model-interaction replay
