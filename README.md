# AutoPlanner GitHub Pages

This branch contains the static AutoPlanner route replay gallery. It does not
contain the Python service, runtime registries, checkpoints, or local paths.

- `index.html`: three-case gallery landing page
- `case-1.html`: SyntheX Figure 1 case 01 interaction replay
- `case-2.html`: SyntheX Figure 1 case 02 interaction replay
- `case-3.html`: SyntheX Figure 1 case 03 occurrence-fixed interaction replay
- `complete-route-graph.html`: backward-compatible case 01 route replay
- `static-route.html`: final static route for Strategy 03
- `model-interaction.html`: backward-compatible case 01 model replay
