## Current Decisions

- The normative system boundary, schema migration, proof ladder, durable
  scheduler, route portfolio, global DAG, and paclitaxel acceptance contract
  are defined in [Architecture V2](ARCHITECTURE_V2.md).
- A Codex coordinator directly spawns specialist child agents before route
  candidates enter the blackboard.
- Typed route consensus preserves source provenance and disagreements; Codex
  role agreement is treated as one correlated model source.
- Each unexpanded precursor first receives a durable stock audit and can launch
  a bounded new direct child-agent team; per-product neighborhoods assemble
  into the typed V2 hypergraph with step-scoped sources, alternatives,
  conflicts, and cycles.
- A strict literature stitch requires a materialized, page-bound exact step in
  an out-of-band trusted registry and independently verified closure for every
  terminal reactant frontier. The package registry is empty by default.
- Stock closure is recomputed against the requested, path/size/SHA-bound real
  catalogs; the common-commodity supplement is explicit and is not a broad
  catalog fallback.
- Codex chooses compact typed follow-up action batches from blackboard state.
- Deterministic validators enforce action schema, budget, source binding, stale
  repetition, raw reaction rejection, and solved-claim rejection.
- Heavy payloads are completed by local builders, not by long prompts.
- Online search is primary; local PDFs are metadata-matched cache/fallback.
- ChemEnzy is a local route generator. It is not final proof.
- Final `solved` requires deterministic parent route proof, exact stock audit,
  and L3 trusted exact precedent (or L4) for every selected reaction. Mapping-
  consistent and transform-replay L2 evidence remains advisory at the parent
  authority boundary.
- Proof-eligible routes are solved as AND/OR closures and selected into a
  diversity-aware Top-K portfolio; a replacement is re-solved, never spliced.
- The full molecule-reaction graph and its closed route DAGs expose a
  multidimensional trust vector and commit route projections as one immutable
  content-addressed revision.
- Route-forest solved branches are rebuilt from revalidated proof inputs;
  consensus, visual, process, and child-only branches remain advisory.
- Legacy molecule-specific semisynthesis rescue is disabled unless explicitly
  opted in for a historical replay.
- A failed Codex multi-agent mainline stops unresolved rather than silently
  switching to a deterministic scientific planner.

The 2026-07-10 paclitaxel replay improved team acceptance, evidence extraction,
and route-forest coverage, but correctly finished
`hypothesis_route_proposed` / `hypothesis_route_execution_partial` with
`solved=false`: no exact trusted literature chain and no verifier-accepted
parent closure were available. See
[AutoPlanner mainline](MAINLINE.md#paclitaxel-end-to-end-run-2026-07-10) for the
artifact-level result and comparison command.
