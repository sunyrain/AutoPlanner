# Architecture evolution visual asset

`architecture-evolution-hero.png` was generated with the built-in `imagegen`
workflow for the architecture review report and presentation.

Prompt intent:

> A premium 16:9 scientific visualization showing a left-to-right transition
> from fragmented single-step models and search trees, through a route board
> and agentic blackboard, into a canonical reaction hypergraph and a compact
> proof-backed route portfolio. Dark navy laboratory-data space, restrained
> cyan/teal/amber/coral highlights, no text, logos, or watermark.

The image is intentionally text-free. Titles, dates, labels, and metrics are
rendered as native document or presentation elements so they remain accurate
and editable.
