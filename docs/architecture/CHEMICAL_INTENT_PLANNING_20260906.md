# 用化学意图与前提依赖驱动逆合成

2026-09-06。本文区分已落地的第一版、待研究的方法与可被证据支持的论文主张。它不替换既有实验快照。真实调用结果见 [本轮检查报告](../evaluation/CHEMICAL_INTENT_CANARY_20260906.md)。

本轮取舍更新：项目以调用现有模型为前提，不具备模型训练条件。强化学习、偏好训练和学习价值网络已从工作路线中移除。当前重点是结构事实的准确传递、失配定位、可回退的路径修订，以及必要时引入外部证据。第 11 节区分确定的局部收益和仍需验证的规划收益；已接通接口不代表已提高化学能力。

2026-09-07 补充：全局模型 Host 已单列为[独立调度实验设计](LLM_HOST_EXPERIMENT_20260907.md)，尚未接入默认流程。先修现有预算、失败评审恢复和操作反馈的可靠性，再用同预算对照判断是否替换调度策略。

## 1. 值得深化的贡献是什么

**把逆合成从逐步生成反应，推进到持续维护和修订一组相互依赖的化学前提。** 模型首先决定当前阶段要建立什么能力、需要哪些前提，再选择落实这些意图的反应；新前体或新证据改变前提时，按其影响范围调整路线。

一个反应的图编辑能重放，说明其结构变化被准确表达。它没有回答：为什么这个底物会沿预期方式反应；前面选定的异构体是否为下一步提供正确几何；当前活化是否破坏另一个片段的反应把手。LLM 的薄弱点尤其在于这些跨步关系容易消失在文本摘要和局部修订中。

现有连续 Strategy 和 checkpoint 是合适的骨架。下一层需要让“关键假设”实际影响搜索、证据选择和修复范围。可以主张的方法方向是 **chemical-intent planning with prerequisite-aware graph revision**。目前没有完成足以确认“首次”的系统相关工作检索，也没有证明对 SynthEx 的总体优越性。

论文中最有区分力的问题表述：

> Can an LLM planner preserve the chemical preconditions of downstream reactions while developing upstream strategies and revising a multistep synthesis?

## 2. 更适合模型操作的对象

| 层次 | 模型需要回答的问题 | 当前载体与本轮状态 |
|---|---|---|
| 化学意图 | 当前最难的承诺是什么？为何值得采用这个构建？ | 连续 Strategy 的 query、critical assumption、checkpoint；本轮补充化学推理指引 |
| 前提依赖 | 哪一步需要什么状态？哪些制备步骤建立或保留它？ | 本轮新增 Critic 的 `chemical_dependencies`，引用实际 review slots |
| 图干预 | 哪些反应或它们提供的状态需要重新考虑？要达到什么结果？ | 本轮 Editor 的 `change_step_ids`、repair goal、active constraints |
| 结构实现 | 在当前真实分子 occurrence 上具体改变哪些原子和键？ | 普通 Builder 的 ReactionJSON；Host 编译为 RouteJSON |
| 观察与评价 | 结构是否接回？前提是否满足？证据是否足够？ | 原有 Host replay、整路 Critic、库存与证据状态，分别记录 |

这里的意图是一个尚待实现的化学要求，例如“提供能够被下游利用的亲核片段”“使环化所需的相对几何成立”。它不是一张保证成立的反应模板，也不是另一个可以宣布 solved 的对象。

本轮保留简短自然语言要求，并以 Host 的反应 occurrence 身份绑定。暂不引入新的巨大 IntentJSON、逐原子义务台账、手性状态副本或第二套路线图。映射、分子和当前版本仍由原图负责；依赖只存在于对应 Critic artifact，反馈与复审从该 artifact 派生。

**尚未实现的部分：** 对未来但尚未展开的步骤维护完整的部分序计划；以机器可检查谓词自动跟踪所有中心、保护基、极性和反应把手；根据依赖自动调度所有需要重评的旧事件。当前依赖模型覆盖已提供的路线步骤，主要进入最终 Critic→Editor 路径。在线 Key Critic 继续使用已有 focus/repair-scope 合同。

## 3. 化学家的先验怎样进入决策

有价值的先验应帮助选择动作，而不只是增加一段背景知识。

| 思维方式 | 对规划的具体影响 | 本轮与后续边界 |
|---|---|---|
| 从最难承诺倒推，再正向检查 | 优先考虑骨架形成、不可轻易逆转的选择性和汇聚连接；说明最弱前提 | 已加入初始及后续 Strategy 提示；尚无收益归因 |
| Retron、潜在对称性、合成子 | 同一骨架可从不同简化视角提出战略 | 已提示比较；没有新增命名反应硬规则 |
| 极性匹配与 umpolung | 片段连接必须具备互补反应性，必要时先建立或转换把手 | 已进入提示及依赖要求；不是确定性机理证明 |
| 立体接力与暂时官能团 | 选择上游状态时考虑它怎样建立、转移或破坏下游要求 | 本轮依赖输出和协调编辑可表达；尚未全中心追踪 |
| 保护和步骤先后关系 | 某次活化、氧化或去保护可能威胁另一计划所依赖的状态 | 通过依赖和 active constraints 交给 Editor；部分序威胁传播待实现 |
| 汇聚与最长线性序列 | 评价实际片段可得性和最长分支，不能靠隐藏困难前体减少步数 | 当前反隐藏前体提示与 exact frontier 保留；尚无新优化目标 |
| 与最强竞争过程比较 | 说明当前底物为什么走目标路径；不能以产物画法证明选择性 | 本轮 Critic 提示比较具体竞争过程；可信度仍需外部检查 |

不要求每个 Strategy 填满这些类别。简单步骤无需重复产生一份化学检查表。先验应服从真实底物；合理但不常见的反应仍可保留为 uncertain。

## 4. Editor 从文档修改转为图干预

模型现在只需给出类似动作：

```json
{
  "change_step_ids": ["consumer", "preparation"],
  "additional_coupled_blocker_step_ids": [],
  "preserved_suffix_compatible": true,
  "repair_goal": "使制备步骤提供能满足下游反应要求的状态",
  "active_constraints": ["保留未被修改片段所需的反应把手"]
}
```

Host 从当前已编译的反应 occurrence tree 得到父子关系。对模型点名的步骤集合 D，计算包含 D 的最小连通子树 C：找到共同祖先，并合并各步骤至该祖先的路径。无关兄弟支路不因它们在数组中夹在两个步骤之间而被删除。

这在树上具有唯一的最小连接区域；并不声称求解任意反应 DAG 上的一般最优图编辑问题。Host 求解的是模型所选节点的拓扑连接范围，**不是最小化学充分修复范围的证明**。如果模型漏选必须改变的制备步骤，最小连通算法不能替它发现化学错误。

Host 派生切口处的精确分子状态，Builder 逐步重建，随后复用原有 suffix stitch、全路 replay 和整路复审。与模型一次写完整 RouteJSON 相比，这把化学范围选择、结构实现和精确拼接分别交给合适的组件。历史两端点 directive 仍可重放；新模型 wire 不再请求这些端点。

**局部通过的步骤也可以被修改。** 如果 A 的产物不满足 B 的前提，Editor 有两类合理选择：保持 A 的精确产物，换成与其相容的 B；或把 A 及相关制备过程一起纳入重建。不能为了允许修复 A，就把本来局部正确的 A 强行判为 reject。

事务保留目标和未选中支线的精确分子切口。替代反应不再需要的试剂制备支线，必须完整纳入现有 `change_step_ids`；其旧终端原料没有保留消费者，因此不再强制重新生成。新终端原料仍须得到 Host 的肯定库存结果或继续合成，不能把未命中的高级中间体当作完成。结构、同位素、立体化学、未被修改的路径、全路重放和化学复审仍是约束；这些规则不增加模型输出字段。

Editor 读取原有 `conditions` 和催化剂的完整内容，不再按字符数或条目数裁切。Critic 仅评价化学及影响反应的分子身份与规格；库存闭合和材料可获得性由 Host 的现有状态报告，不从 Critic 文字推断，也不要求其在路线化学总评里重复判定。

## 5. Critic 需要评价因果关系，并保留不确定性

本轮最终 Critic 增加最多六条重要依赖：消费者、提供前提的步骤、该前提的简短描述。Host 只核对引用和去重，不把模型的依赖推断升级为化学事实。非法的辅助依赖会产生诊断并被丢弃，已经有效的逐步评审仍保留。

重建后的 step ID 通常变化，原 ID 消失不表示问题已解决。复审现在从原 Critic 和当前修复目标派生 `repair_requirements_to_reassess`，把原问题交给新 Critic，要求基于新结构独立判断。它不继承旧 verdict，不生成第二个“修复分数”，也不只检查被修改的步骤。候选依然接受整路评审。

必须区分：

- **结构观察：** 连接关系、映射身份、目标与切口、可计算的相对立体关系。
- **化学假设：** 某状态能够实现预期机制、选择性或相容性，允许被后续信息修正。
- **外部证据：** 特定底物或近邻底物的实验先例、可定位的条件与结果、专家判断。

本轮 BCH 检查已经说明限制：模型正确列出了三步依赖，却把原来明确拒绝的关环几何降为 uncertain。因此增加字段和化学提示无法单独解决 Critic 的知识、空间推理和判断校准问题。需要有针对性的结构观察和真实证据；不能只通过收紧提示让模型多报 reject。

## 6. 无需训练的规划控制

按当前项目约束，不做 RL、偏好训练或学习价值网络。上一版把这些写成三个后续阶段，超出了可执行范围，应予撤回。也不另建 reward model、训练数据管线或 reward 台账。当前 Critic 的判断稳定性不足，用其输出构造奖励还可能放大错误。

可以保留几种不依赖训练的具体做法：连续 Strategy 规定当前阶段要解决的问题；在有决策意义的事件检查它；保留有效路径与失败尝试；按已知冲突选择重试当前动作、回到较早的结构选择、扩大修复范围或更换战略。这些直接作为规划和搜索机制描述即可，不必用 RL 术语包装。

其中“冲突可定位”不等于“正确回退点已知”。分子身份不匹配可以由 Host 准确发现；究竟应修改产生它的反应、较早的前体选择，还是增加一个合理的转换，仍须结合化学判断。回退候选应在现有事务中比较，不另建一个控制器或全局惩罚函数。

已有 I/O 用于故障回放、版本对照和独立化学评审。评价分别记录同边界任务完成、原问题是否解除、新问题、剩余不确定性和成本；它们不自动合成为一个由同源模型打分的奖励。是否保存某项新反馈，取决于它能否影响下一次实际选择，而非是否适合构建新的数据 schema。

## 7. 主动选证据，比大量泛搜更接近真正的进步

理想的检索单位应是“当前哪个未决前提会改变下一步决策”。例如先分清这是相对构型读取问题、反应族知识问题、底物适用性问题，还是只有实验才能区分的竞争速率问题。

对应动作可以是一次确定性结构检查、一次针对反应中心与底物环境的 Reaxys/SciFinder 检索、阅读具体原文/SI，或者把关键未知保留给专家和实验。选择依据是结果对“继续、扩大修复范围、更换 Strategy”的影响及成本，不是网页调用总数。

学校拥有数据库订阅不自动意味着程序可以调用厂商 API；优先使用许可范围内的查询、人工导出或正式接口。应把关键先例绑定到具体前提，保存原始定位与相似性差异。检索不到不能直接判反应失败，找到同名反应也不能直接证明当前底物可行。

本轮没有实现厂商数据库接入或信息价值调度。新依赖结构提供了检索焦点，但还未把它自动编译为检索任务。

## 8. 与 SynthEx、图编辑及规划前人的关系

SynthEx 已有 Strategy、结构化 ReactionJSON、MCTS、最终 Critic/Editor 和真实修复示例。不能再把“有 Critic”“用图编辑”“保留战略”当成它没有的能力。其主论文 Fig. 5 的顺序修改必须纳入公平比较。

值得检验的差异是：连续形成新阶段战略、提前检验关键前提、显式连接跨步要求、通过语义干预协调修改并检查保留步骤。这是一组具体的机制主张，不是对方所有错误均已被我们解决的结论。此前 Cyclopiamine B 的风险识别尚无同靶点成功修复；本轮 BCH 是我方路线的回归案例，不能充当修好对方路线的证据。

## 9. 如何证明本质差异

第一组实验测试表示与操作是否有作用：在固定旧路线与经独立校核的原问题下，比较文档 Editor、原两端点 Editor、语义节点集合 Editor，以及后者加入显式前提依赖。保持 Builder、Host、精确任务边界和总预算一致。报告修复原问题的比例、过度改动、引入新问题、失败/无输出、调用成本。单次模型判断不能作为唯一终点。

第二组实验测试整体规划：保持相同模型、初始未经预审的战略或 target-only 输入、库存和工具权限，分别评价固定/连续 Strategy，终点/逐步/关键事件 Critic。绘制预算与质量曲线；同 token 下再比较均匀选点与事件选点，避免把“多花算力”解释成机制收益。

主终点应是固定资源内、每目标至少得到一条完整且经盲评未发现严重化学矛盾的有研究价值候选。库存闭合、文献恢复、模型认可和实验成功分别报告。天然产物 benchmark 同时保留文献路线和可信替代路线，不能只用 exact route match 评价创造性。

数据库尤其应支持四类任务：缺陷定位、前提来源定位、最小充分修改区域、同边界修复。真实成功路线提供正例；谨慎构建并人工核验的反事实变体测试灵敏度；真实失败轨迹测试分布外问题。需要记录评审分歧，特别是“具体矛盾”和“尚待实验”的边界。开发、示例检索与最终评测按论文/骨架/路线族隔离，避免将参考答案作为模型输入后再称为独立规划。

## 10. 本轮实施与后续拆分

已落地：集中化学推理指引；最终 Critic 依赖 wire、绑定及反馈传播；Editor 语义动作与历史兼容；最小连通图区域；复审保留原问题；预算跳过原因日志。新增 `chemical_reasoning.py` 和 `repair_scope.py`，并从巨型编排文件移出约 148 行原有 blocker component/复审范围逻辑。新逻辑不包含 BCH 名称、固定 atom map、某反应名称或某个具体立体方向的分支。

巨型编排模块仍然需要继续拆分。下一阶段应沿已有真实边界依次移出 repair transaction 的快照/重建/提交状态机、Strategy horizon 调度、Critic prompt 和绑定投影。保留唯一预算与 journal，避免用新的 manager、状态副本或多套兼容 wrapper 再把依赖绕回去。本轮只完成化学推理及图范围选择的第一步拆分。

最优先的后续能力缺口是：Critic 的结构观察与拒绝校准、失配后的修复动作选择、跨新上游步骤的前提复审调度，以及经独立评审的路线与修复评价集。优先把已出现的失败修到可解释，再决定是否扩大依赖表示和自动检索。获得相应消融结果后，才能把方法候选写成强结论。

## 11. 哪些值得接，哪些收益未定

“确定有用”在这里仅指能消除一个明确的错误或信息损失，不指保证天然产物路线成功率提高。新增接口、日志、模型角色或检查器本身均没有这样的保证。

| 改动 | 能确定的局部收益 / 不确定性 | 决策 |
|---|---|---|
| 原始条件、结构和有效评审的忠实传递 | 已出现条件被删、立体等价误拦、调用失败覆盖有效判断；可对同一输入验证修复 | 最高优先级，已有修复继续维护；保留可被新有效证据修正的判断，不永久锁定旧 verdict |
| 从实际图编译修改范围及精确切口 | 对给定节点集，可避免数组切片误删 sibling 和假接回 | 保留；不声称模型选择的范围一定化学充分，也不把局部 same-frontier 约束扩成所有规划的限制 |
| 给模型直接呈现必要结构事实 | 减少模型猜 atom maps、对应原子、净键变化、已有立体标注的负担 | 优先从当前 Host 的检查结果派生紧凑视图；不能把 CIP 字母变化直接当成物理反转 |
| 正确区分故障、矛盾和未知 | 工具失败不等于化学失败，未找到文献不等于反应不可能 | 保留清晰状态归属；不要求每个状态再经过一次 LLM 判决 |
| 连续 Strategy | 能支持新子目标与失败后的换路，但也可能漂移、重复或过早更换好战略 | 保留为主干，按新子目标或真正的假设变化触发；化学收益仍需对照 |
| 稀疏 checkpoint | 可能早发现问题并节约后续展开，也可能漏检或提前误杀 | 保留关键事件与受影响接口的审查；不默认逐步全审，也不只相信 Builder 自报关键事件 |
| Editor 明确选择修改节点 | 降低模型计算数组边界的负担；独立 Editor→Builder 的交接仍可能丢失意图 | 保留现有可执行动作；用真实修复评价是否优于原 Editor，不因增加角色而自认更强 |
| `chemical_dependencies` 等辅助字段 | 上轮已能输出正确关系，但未证明检测或修复收益 | 作为紧凑、问题相关的实验功能；不再扩成全路线强制义务清单 |
| retron/极性/对称性等提示 | 模型可能已知道；更多提示也可能诱发命名反应偏好或虚构控制 | 保持简短，不继续堆砌；用其实际改变的战略与结果判断价值 |
| 立体意图的可执行操作 | 可减少文字意图与低层编辑不一致，但反应中配体替换、对称性和多中心变化使通用定义困难 | 高价值候选；先限定到可定义的结构语义，检验物化结果，不能直接把一句“反转”当成机理证明 |
| 冲突定位与回退 | 当前已有同父重试；对较早错误选择的回退有明确需求，但单次 mismatch 未必确定根因 | 优先小规模实现与验证候选回退；不按固定失败次数或同骨架即错误的规则剪枝 |
| 定向文献证据 | 准确原始实验可增加决策信息；自动召回、类比与适用性仍可能错误 | 从关键未知的一次检索/人工导入做起，避免全路线泛搜与数据库接入工程先行 |
| 巨型模块拆分 | 提高清晰度和修改可控性，不能直接提高化学知识或路线质量 | 沿实际职责逐步拆，不引入新的状态副本或多层 manager |

**已收窄中间体提前剪枝。** `_path_repair_boundary_stereo_conflict` 能正确识别“连接关系相同、立体不同”，现在仅用于最终拼接拒绝与当前叶子的结构观察，不再提前拒绝中间候选。该事实足以禁止把它直接冒充精确边界；它不足以证明不存在后续合法转换。例如一般形式 `目标 ← 暂时异构体 ← 边界异构体` 并不因两个异构体连接关系相同就不可成立。这不意味着 BCH 已有可行修复；最终化学可行性仍由复审与实验区分。

精确拼接、目标侧保留步骤、原子对应及出现次数仍是 Host 不变量。立体差异读取和边界比较的 137 行逻辑已移入已有 `path_repair_boundary.py`，没有第二套结构状态。新进程使用本轮实现，现有服务未重启。

修复期间的 Builder 可返回 `recovery.action=expand/backtrack/expand_scope`。`expand` 继续当前转换或纠正当前编辑；`backtrack` 只能选择当前搜索路径中保留边界之后的临时步骤，复用 AiZ 的子树剪除与父节点恢复；`expand_scope` 结束本次临时重建，把具体原因交回原有 Editor 事务。回退没有化学拒绝权，扩大范围没有直接修改权。Host 只在真实控制动作处验证权限，正常 `expand` 附带的参考 ID 不会导致有效反应被丢弃。

恢复请求与 replay failure 共用事务的实际上下文；已删除内外复制导致请求丢失的状态副本。下一次 Editor 从历史事务读取范围、原因与临时前体，不另建失败管理器。Editor/Builder/复审仍共享原有调用和 token 预算；没有固定“失败 N 次就认定反应不可能”的规则。

本轮已完成冻结状态下的连续 Strategy、checkpoint、依赖反馈配对及五份匿名独立模型评审。连续 Strategy 对照保留双方 checkpoint；checkpoint 对照固定双方里程碑上限为 1；依赖对照固定路线与 Critic 文本，仅改变依赖投影。复审拒绝后的第二次 Editor 也已由真实运行验证；其发现从现有 Critic history 投影，不携带失效候选 ID，不重复审查未改变的原路线。模型尚未得到新的已提交化学修复，部分试验还有预算超额或缺失用量，不能宣称整体质量提高。详见 [控制与对照报告](../evaluation/CHEMICAL_INTENT_CONTROL_AND_ABLATION_20260906.md)。代码入口见 `docs/evaluation/evidence/chemical_intent_canary_20260906/paired.py` 与 `review_paired.py`。

RL、全面 IntentJSON、自动全分子机理判定、多 Critic 投票和全量泛搜均不进入近期主线。
